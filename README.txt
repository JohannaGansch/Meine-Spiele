Die Website bildet Unity_Spiele/Website rekursiv ab.
Jeder Ordner ist eine Kategorie, solange er keine Spiel-Dateien enthält.
Ein Ordner mit App.exe oder B0/B1... oder V0/V1... wird als Spiel erkannt.
Bild = Kategorie-Bild, Beschreibung = Beschreibung, B0 = großes Bild, B1... = Bilder, V0/V1... = Videos.
